- [ ] Confirm no tracked PDFs: `git ls-files | grep -i '\.pdf$'` is empty.
- [ ] Run `python3 tools/check_publish.py --public`.
- [ ] Run `python3 tools/check_references.py` and `python3 tools/check_doc_paths.py`.
- [ ] Flip visibility, then enable the branch ruleset (PR, 1 approval, code owners, status checks).
