# Reference manifest

Third-party PDFs, datasheets and the vendor snapshot are **not committed**.
`manifest.yml` is the source of truth; `MANIFEST.md` is generated from it.

- `manifest.yml` — one entry per external file: ID, size, which docs use it, how
  to obtain it, publish permission, SHA-256, regeneration command.
- `MANIFEST.md` — the human-readable table and acquisition details. Generated by
  `python3 tools/gen_reference_manifest.py`.
- `anser-osf-provenance.md` — the tracked provenance summary for the OSF
  snapshot (`vendor/` is local-only).

## Add a reference

1. Add an entry to `manifest.yml` with an acquisition method (URL/DOI/OSF node/
   course Moodle/author) and a local path.
2. Run `python3 tools/gen_reference_manifest.py`.
3. Run `python3 tools/check_references.py`.

If a doc references a third-party file without a manifest row, the checker
fails. That is intentional: a reference nobody can obtain is not a reference.
